# Social Media Posts for CheapEats Canberra

## Facebook Post

Hey Canberra foodies! 🍽️

I've been working on something I'm pretty excited about - **CheapEats Canberra** (cheapeatscanberra.com.au). It's a simple website that helps you find the best restaurant deals, happy hours, and weekly specials around our city.

This is a passion project I built because I got tired of hunting through Facebook pages and websites trying to find good deals. I wanted one place where I could see what's happening around town. It includes deals from EatClub and First Table too, so you can see everything in one spot!

**A few things to know:**
- It's still early days, so there might be some errors or missing info - I'm learning as I go! 😅
- I'm not running any ads on the site. This is purely about helping the community find great food deals.
- The best part? You can submit deals you find! I really believe this works best when it becomes a community resource where we all help each other out.

If you find a deal that's not listed, or spot something that needs fixing, please let me know. Together we can build something really useful for everyone.

If you'd like to support the project, you can buy me a coffee: https://ko-fi.com/dbronitt ☕

Check it out and let me know what you think! 🎉
